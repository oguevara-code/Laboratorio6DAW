# Laboratorio 6 - Bases de datos
## Sistema de matrículas

## Descripción
El presente proyecto consiste en el diseño e implementación de una base de datos para un sistema de matrículas estudiantiles. El sistema permite registrar estudiantes, cursos y matrículas, además de relacionar los cursos en los que un estudiante se encuentra matriculado.

La base de datos fue desarrollada utilizando PostgreSQL y posteriormente implementanda en Supabase para su visualización en la nube.

---

## Tecnologías utilizadas
- PostgreSQL
- Supabase
- Visual Studio Code
- Draw.io (para hacer el DER)

---

## Entidadaes principales

La base de datos está compuesta por las siguientes tablas:
- students
- courses
- enrollments
- courses_enrollments

Estas tablas permíten representar las relaciones entre estudiantes, cursos y matriculas.
